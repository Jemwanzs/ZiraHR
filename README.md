# ZiraHR Marketing Website

The official ZiraHR product marketing/landing website — a standalone Next.js project, separate from the main ZiraHR HRMIS application, built to represent it accurately.

## Documentation

Full project documentation lives in [`/docs`](./docs), organized as:

- [`00-source`](./docs/00-source) — the original scope and kickoff brief this project is built from
- [`01-product`](./docs/01-product) — positioning, target market, module catalog
- [`02-ux`](./docs/02-ux) — information architecture, homepage scope, product pages, responsive behaviour
- [`03-brand`](./docs/03-brand) — visual design system, colors, typography, motion
- [`04-content`](./docs/04-content) — approved copy (homepage, product, CTA, footer)
- [`05-seo`](./docs/05-seo) — SEO strategy, keyword map, metadata plan, structured data, internal linking
- [`06-technical`](./docs/06-technical) — architecture, component structure, routing, Supabase, notifications, deployment, performance
- [`07-localization`](./docs/07-localization) — localization strategy and translation key conventions
- [`08-assets`](./docs/08-assets) — asset requirements and the screenshot/video placeholder plan
- [`09-qa`](./docs/09-qa) — QA, accessibility, SEO, and launch checklists

Read [`docs/06-technical/architecture.md`](./docs/06-technical/architecture.md) first for the stack and phase plan.
