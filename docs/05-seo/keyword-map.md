## Rules

- `/hr-software-kenya`, `/payroll-software-kenya`, `/hrmis-kenya` target overlapping-sounding but distinct intents — each needs a clearly different angle (category overview vs. payroll-specific depth vs. "HRMIS" terminology searchers) so they don't cannibalize each other. Confirm differentiated content outlines before writing final copy.
- Do not add new SEO target pages beyond this table without checking they don't duplicate an existing page's intent.
- Country-specific expansion pages (beyond Kenya) are added to this table only once that country is actually supported — see `01-product/target-market.md`.
