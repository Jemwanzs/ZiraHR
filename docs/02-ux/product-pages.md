# Product / Module Pages

Each page below is a full SEO landing page, not a re-statement of the homepage module card. Every page needs its own hero headline, its own workflow demonstration, and its own unique copy — never copy-pasted between pages with nouns swapped.

## `/payroll`
SEO targets: payroll software Kenya, Kenya payroll software, HR and payroll software, cloud payroll system Kenya.
Hero: "Payroll without spreadsheet gymnastics."
Showcase: Payroll Cycles, Basic Pay, Allowances, Benefits, Deductions, PAYE, NSSF, SHIF, Housing Levy, Reliefs, Salary Advances, Payslips, Payroll Approvals, Bank Files, Disbursements, Payroll Analytics.
Constraint: no unsupported statutory/automation claims.

## `/leave-management`
Hero: "Leave management that keeps everyone in sync."
Flow demo: Employee requests → Manager approval → Workflow routes automatically → HR sees calendar → Balance updates.
Showcase: leave policies, accruals, carry forwards, multi-level approvals, leave calendar, balances, reports, ESS tie-in.

## `/attendance-management`
Hero: "Know who's working. Without chasing attendance sheets."
Showcase: Clock In/Out, Geo-fencing, Attendance rules, Branch locations, Late arrivals, Overtime, Shifts, Rosters, Timesheets, Attendance analytics. Include mobile UI mockups.

## `/core-hr`
Primary message: "One reliable record for every employee."
Showcase: Employee Directory, Employee 360 Profile, Organization Structure, Branches & Regions, Departments, Job Grades, Job Positions, Employee Lifecycle, Promotions, Transfers, Temporary Assignments, Onboarding, Offboarding, Documents.

## `/recruitment`
Flow demo: Requisition → Job Board → Applications → Shortlist → Interview → Offer → Hire, final animation morphs the candidate card into an employee profile card (visual proof of the connected-platform story).

## `/performance-management`
Hero: "Turn goals into conversations. Conversations into growth."
Showcase: Goals, KPIs, Review Cycles, Appraisals, Continuous Feedback, 360 Feedback, PIP, Analytics.

## `/learning-development`
Flow demo: Skills → Learning → Assessment → Certification → Growth.
Showcase: Training Programs, Courses, Enrollments, Assessments, Certificates, Skills, Competencies, Development Plans.

## `/teams-collaboration`
Tone: energetic, visually interactive — positions SoftHR as more than an administrative system.
Showcase: Workspaces, Teams, Channels, Messaging, Announcements, Notifications, Employee collaboration.

## `/employee-self-service`
Hero: "HR isn't only for HR." / "Give every employee a simpler way to manage their work life."
Desktop + mobile shown together. Capability checklist: View Profile, Update Details, Download Payslips, Request Leave, Check Leave Balance, View Attendance, View Goals, Complete Learning, Receive Notifications, Access Documents, Follow Approvals.

## `/analytics`
Four dashboard experiences: Executive, HR, Finance, My Dashboard. Headline: "Different roles. Different questions. The right answers."

## `/ask-tija`
Headline: "Meet TiJa. Ask your workforce."
Example queries (shown as animated prompts, not live-executed): "Who has contracts expiring this month?", "Show pending leave approvals.", "Explain this month's payroll variance.", "Which employees have missing bank details?"
Position: workforce intelligence inside SoftHR — never framed as a generic chatbot.

## Shared page template

Every module page follows the same skeleton (`ProductPageLayout` component): hero (headline + one-line subhead + CTA pair) → capability showcase (left-nav/right-stage or workflow diagram, matching the homepage module-showcase pattern) → "how it connects" callout linking back to Core HR's single employee record → page-specific FAQ (only if genuinely applicable, scope §34) → footer CTA. This keeps the visual language consistent while every page's *content* stays unique per the no-duplicate-copy rule.
